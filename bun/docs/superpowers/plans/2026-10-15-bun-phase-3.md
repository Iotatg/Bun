# Bun Phase 3 — Error Handling, `list.sort()`, and Tool Conversion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add JS-style `try`/`catch`/`throw` runtime error handling, an in-place `list.sort()` method, and convert the Bun runtime's `mime_type_list` table generator to Bun — plus four cheap+safe fixes deferred from Phase 2 (REPL checker persistence, module error frames, golden dedup, a `../`-import golden).

**Architecture:** `try`/`catch`/`throw` are pure syntax + interpreter changes: three new tokens/keywords, two new AST nodes, a parser dispatch branch, and one `_execute_try` helper that catches `BunRuntimeError` and runs the catch block in a child environment holding the message string. `sort()` is one method in `bun/methods.py`. The mime conversion is a Bun module under `tools/mime_type/` driven by a golden test that imports it through a `../../` path. No checker rules exist for try/catch other than "check both blocks in branch-copy scopes".

**Tech Stack:** Python 3.8+, pytest, standard library only.

## Global Constraints

- Python >=3.8; stdlib only; zero third-party deps.
- No raw Python exceptions may escape; every error stays in the `BunError` family with line/col.

- No `break`/`continue` exists in Bun; write loops with `while` + flags.

- Use `python3` (no `python` on PATH).
- Deletions of existing files require explicit user approval first (no-delete rule); the implementer never deletes.

        kw = self._advance()
        try_block = self._block()
        params = []
        if self._match(TokenType.CATCH):
            if self._match(TokenType.LPAREN):
                name = self._expect(TokenType.IDENT, "expected exception name")
                self._expect(TokenType.RPAREN, "expected ')' after exception name")

    def _throw_stmt(self):
        kw = self._advance()
        value = self._expression()
        return ast.ThrowStmt(value, kw.line, kw.col)

### Task 2: Execute `try`/`catch`/`throw` (interpreter, tests, golden)

**Files:**
- Modify: `bun/interpreter.py` (`_execute` dispatch + `_execute_try`)
- Test: `tests/test_try.py` (new)
- Test: `tests/golden/try_catch.bun` + `tests/golden/try_catch.out` (new)

**Interfaces:**
- Consumes: `ast.TryStmt`, `ast.ThrowStmt` (Task 1); `stringify` (already imported).
- Semantics (from the Phase 3 design spec):
  - `try` catches **`BunRuntimeError` only** (runtime errors). `LexError`/`ParseError` happen before execution; `BunTypeError` happens in the check phase — none are catchable.
  - `throw <expr>` raises `BunRuntimeError(stringify(value), node.line, node.col)`.
  - The catch parameter binds the error's **message string** in a child environment of the enclosing scope; the catch block runs in that child's own block scope (parameter does not leak).
  - `ReturnSignal` from inside `try` propagates normally (not caught).
  - An error raised inside the catch block propagates (no re-catch by the same try).

def l_sort(recv, args):
    _arity("sort", args, 0)
    numbers = 0
    strings = 0
    for item in recv:
        if isinstance(item, bool) or not isinstance(item, (int, float, str)):
            raise BunRuntimeError("cannot sort list with mixed types")
        if isinstance(item, str):
            strings += 1
        else:
            numbers += 1
    if numbers and strings:
        raise BunRuntimeError("cannot sort list with mixed types")
    recv.sort()
    return None
```

Create `tools/mime_type/mime_type_list.bun`:

```bun
// Converted from bun-runtime/src/http_types/mime_type_list.generate.ts.
// Deviations from the TypeScript original:
// - latin1 Buffers -> Bun strings (MIME names are ASCII, so byte order and
//   string order agree).
// - the (length, bytes) sort -> length buckets with sort() inside each
//   bucket (list.sort() sorts by <, the same order for ASCII names).
// - JSON.stringify escaping -> manual backslash/quote escaping plus the
//   same space -> \x20 replacement (data is printable ASCII).

export fn generate(list_text) {
    var seen = {}
    var names = []
    var max_len = 0
    for line in list_text.split("\n") {
        if line != "" {
            if !seen.has(line) {
                seen[line] = true
                names.push(line)
                if len(line) > max_len {
                    max_len = len(line)
                }
            }
        }
    }
    if len(names) == 0 {
        throw "mime list is empty"
    }

    var by_len = {}
    for name in names {
        if !by_len.has(len(name)) {
            by_len[len(name)] = []
        }
        by_len.get(len(name)).push(name)
    }

    var blob = ""
    var bucket_rows = []
    var offset = 0
    var position = 0
    var length = 0
    while length <= max_len + 1 {
        bucket_rows.push("(" + str(offset) + ", " + str(position) + ")")
        if by_len.has(length) {
            var bucket = by_len.get(length)
            bucket.sort()
            var i = 0
            while i < len(bucket) {
                blob = blob + bucket[i]
                offset = offset + length
                position = position + 1
                i = i + 1
            }
        }
        length = length + 1
    }

    var escaped = ""
    for ch in blob {
        if ch == "\\" {
            escaped = escaped + "\\\\"
        } else if ch == "\"" {
            escaped = escaped + "\\\""
        } else {
            escaped = escaped + ch
        }
    }
    escaped = escaped.replace(" ", "\\x20")

    var chunks = []
    var at = 0
    while at < len(escaped) {
        var end = at + 100
        if end > len(escaped) {
            end = len(escaped)
        }
        var scan = end - 1
        while scan >= at and escaped.slice(scan, scan + 1) != "\\" {
            scan = scan - 1
        }
        if scan >= at and scan > end - 4 and end < len(escaped) {
            end = scan
        }
        chunks.push(escaped.slice(at, end))
        at = end
    }

    var rows = ""
    var row_index = 0
    while row_index < len(bucket_rows) {
        if row_index == 0 {
            rows = rows + "    " + bucket_rows[row_index]
        } else if row_index % 8 == 0 {
            rows = rows + ",\n    " + bucket_rows[row_index]
        } else {
            rows = rows + ", " + bucket_rows[row_index]
        }
        row_index = row_index + 1
    }

    var out = "// Generated by mime_type_list.generate.ts from mime_type_list.txt; do not edit.\n\n"
    out = out + "/// " + str(len(names)) + " MIME strings sorted by (length, bytes), concatenated.\n"
    out = out + "#[rustfmt::skip]\n"
    out = out + "pub(crate) static NAMES: &[u8] = b\"\\\n"
    out = out + chunks.join("\\\n")
    out = out + "\";\n\n"
    out = out + "/// `(NAMES offset, sorted position)` of the first name of each length, plus a sentinel.\n"
    out = out + "#[rustfmt::skip]\n"
    out = out + "pub(crate) static BUCKETS: [(u32, u32); " + str(len(bucket_rows)) + "] = [\n"
    out = out + rows
    out = out + ",\n];\n"
    return out
}
```

    unique.sort(key=lambda s: (len(s), s.encode("latin1")))
    max_len = len(unique[-1].encode("latin1"))

    blob = ""
    buckets = []
    offset = 0
    position = 0
    i = 0
    for length in range(0, max_len + 2):
        buckets.append("(%d, %d)" % (offset, position))
        while i < len(unique) and len(unique[i].encode("latin1")) == length:
            blob += unique[i]
            offset += length
            position += 1
            i += 1

    escaped = json.dumps(blob)[1:-1].replace(" ", "\\x20")
    lines = []
    at = 0
    while at < len(escaped):
        end = min(at + 100, len(escaped))
        last_backslash = escaped.rfind("\\", 0, end)
        if last_backslash >= at and last_backslash > end - 4 and end < len(escaped):
            end = last_backslash
        lines.append(escaped[at:end])
        at = end

    rows = ""
    for i, entry in enumerate(buckets):
        if i == 0:
            rows += "    " + entry
        elif i % 8 == 0:
            rows += ",\n    " + entry
        else:
            rows += ", " + entry

    return (
        "// Generated by mime_type_list.generate.ts from mime_type_list.txt; do not edit.\n\n"
        + "/// %d MIME strings sorted by (length, bytes), concatenated.\n" % len(unique)
        + "#[rustfmt::skip]\n"
         + 'pub(crate) static NAMES: &[u8] = b"\\\n' + "\\\n".join(lines) + '";\n\n'
         + "/// `(NAMES offset, sorted position)` of the first name of each length, plus a sentinel.\n"
         + "#[rustfmt::skip]\n"
         + "pub(crate) static BUCKETS: [(u32, u32); %d] = [\n" % len(buckets)
        + rows
        + ",\n];\n"
    )


with open(sys.argv[1]) as handle:
    sys.stdout.write(generate(handle.read()))
```

    scope = {}
    while True:
        try:
            line = input("bun> ")
        except EOFError:
            print()
            break

            continue

            program = Parser(Lexer(line).tokenize()).parse()
            if check:
                scope = checker.check(program, base_dir=os.getcwd(), scope=scope)
            for statement in program.statements:
                if isinstance(statement, ast.ExprStmt):
                    value = interpreter.evaluate(statement.expr, interpreter.globals)
                    if value is not None:
                        print(stringify(value))

## Error handling (Phase 3)

`try`/`catch`/`throw` handle runtime errors, JavaScript-style:

```bun
fn parse_age(text) {
    try {
        return int(text)
    } catch e {
        return -1
    }
}

print(parse_age("42"))
print(parse_age("abc"))
```

- One `catch` per `try`; the parameter is optional (`catch (e)` or `catch {}`).
- `throw` takes any value; the catch parameter receives its message string.
- Catchable: runtime errors (undefined variables, bad indexes, division by
  zero, ...).
- Not catchable: lexer, parser, and type errors — they run before your code.

Lists also sort in place:

```bun
var names = ["cherry", "apple", "banana"]
names.sort()
print(names.join(", "))
```
```
